Set the config's `version` and install that fleetfizz here, with the package manager that installed this one. The next Ship installs it on every Machine.

| Argument | Description |
| --- | --- |
| `<version>` (optional) | An exact version. Default: the newest published. |

| Flag | Description |
| --- | --- |
| `--config <path>` | The config file. Default: `$XDG_CONFIG_HOME/fleetfizz/config.jsonc`. |
